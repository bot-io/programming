Implement a **stamina/sprint system** for the Critterium particle simulation at D:\programming\Tools\critterium.

## Requirements
- Each species has a `sprintDuration` (seconds) and `sprintCooldown` (seconds) in its config
- Sprint determines how long a particle can maintain max speed
- After sprint expires, the particle's effective max speed drops to some fraction (e.g. 50%) until cooldown elapses
- Then it can sprint again
- **Prey typically has higher stamina (longer sprint, shorter cooldown) — this is key for predator-prey dynamics**
- Prey can outrun predators in short bursts but predators have better sustained speed... or prey has better endurance. The user should be able to configure this.

## Implementation

### 1. Core config changes (packages/core/src/ecosystem.ts)
Add to `SpeciesConfig` or a new `StaminaConfig`:
```
sprintDurationSec: number    // how long max speed can be maintained (default: 5)
sprintCooldownSec: number    // recovery time before sprinting again (default: 3)
sprintSpeedMultiplier: number // effective max speed during sprint (default: 1.0 = normal maxSpeed)
tiredSpeedMultiplier: number  // effective max speed when tired (default: 0.5 = half maxSpeed)
```

### 2. Core state (packages/core/src/ecosystem.ts)
Add to `EcosystemState`:
- `sprintTimer: Float32Array` — time remaining in current sprint burst (< 0 = tired/cooldown)
- `sprintCooldown: Float32Array` — time remaining in cooldown

### 3. Sprint logic (new file or in ecosystem-world.ts)
Each step:
- If sprintTimer > 0: particle uses full maxSpeed (or sprintSpeedMultiplier × maxSpeed). Decrement timer.
- If sprintTimer hits 0: enter cooldown. Set sprintCooldown = config.sprintCooldownSec.
- If in cooldown (sprintTimer <= 0 && sprintCooldown > 0): particle speed capped to tiredSpeedMultiplier × maxSpeed. Decrement cooldown.
- If cooldown reaches 0: reset sprintTimer = config.sprintDurationSec, ready to sprint again.

The sprint should be triggered automatically whenever the particle is moving fast (above some threshold of maxSpeed).

### 4. Config schema (packages/core/src/config-schema.ts)
Add stamina fields to serialization/deserialization with defaults:
- sprintDurationSec default 5
- sprintCooldownSec default 3  
- sprintSpeedMultiplier default 1.0
- tiredSpeedMultiplier default 0.5

### 5. UI controls (packages/app/src/controls.ts)
