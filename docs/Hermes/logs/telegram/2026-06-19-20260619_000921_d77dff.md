## Word Tap Translation

**How it works:**
- **Double-tap** any word in the original text → translates it to your target language
- **Double-tap** any word in the translation box → translates it back to the source language
- A floating popup appears at the bottom showing: the word you tapped + its translation
- Tap the popup or the ✕ button to dismiss

**Technical details:**
- Uses `TextLayoutResult.getOffsetForPosition()` to map the tap location to a character offset, then extracts the word boundaries
- Double-tap gesture (`detectTapGestures(onDoubleTap=...)`) — doesn't conflict with native text selection (which uses long-press)
- Single word translation goes through the same `FallbackTranslationService` (Gemini cloud → ML Kit fallback)
- Popup shows loading spinner while translating, then the result
- If translation fails, shows the error message

The direction is automatic — it knows which text you tapped (original vs translated) and flips source/target accordingly.
